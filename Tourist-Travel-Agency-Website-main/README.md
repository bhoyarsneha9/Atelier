# Atelier Travel — Premium React Redesign

A refined redesign of the original Tourist travel-agency website. The project remains built with React 18 and React Router; the existing pages, route structure, image assets, and main site sections are preserved. Visual styling has been refreshed with an editorial serif/sans pairing, warm ivory surfaces, charcoal navigation, muted terracotta accents, softer borders, and responsive spacing.

## Run locally

1. Install Node.js LTS (includes npm): https://nodejs.org/
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm start` and open the local URL shown in the terminal (usually http://localhost:3000).
5. To create a production build, run `npm run build`.
